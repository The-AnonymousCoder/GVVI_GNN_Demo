# GVVI 五档分类模型说明书

## 一、任务定义

给定研究区内 27,597 个 10m 绿化网格，利用静态空间特征预测每个网格的综合绿化可见度（GVVI）所属档次。任务形式为**五档分类**。

### 1.1 五档定义

| 档位 | GVVI × 100 | 原始 GVVI 范围 | 含义 | 全量节点数 | 占比 |
|------|-----------|---------------|------|-----------|------|
| C0 | = 0 | 0 | 无可见绿化 | 7,307 | 26.5% |
| C1 | < 5 | (0, 0.05) | 微量可见 | 14,155 | 51.3% |
| C2 | 5 ~ 15 | [0.05, 0.15) | 中等可见 | 5,383 | 19.5% |
| C3 | 15 ~ 30 | [0.15, 0.30) | 较高可见 | 685 | 2.5% |
| C4 | ≥ 30 | [0.30, 0.556] | 最高可见 | 67 | 0.2% |

GVVI = 3/6 × normalize(GVVI_S) + 2/6 × normalize(GVVI_W) + 1/6 × normalize(GVVI_D)，理论范围为 [0, 1]，实际观测最大值为 0.556。

### 1.2 数据划分

- 训练集：80%（22,066 节点）
- 验证集：5%（1,385 节点）
- 测试集：15%（4,146 节点，**永久冻结**）
- 分层策略：按 GVVI 分位数分层抽样，seed=42

### 1.3 任务性质

**同一研究区内的传导式节点分类**。模型使用全图消息传播（训练节点 + 测试节点的特征都参与图卷积），但测试标签从未参与损失计算。

**不是**跨区域泛化、跨城市泛化或零样本预测。

## 二、输入特征（214 维）

### 2.1 几何观察点特征（196 维）

基于三类观察点（SVI 街道 18,096 个、WVI 窗口 84,936 个、DVI 无人机 17,424 个）的位置、高度、方向计算。

| 特征类 | 维数 | 说明 |
|--------|------|------|
| 距离统计 | 48 | 50/100/250/500m 半径内每类视点数、最近/平均/标准差距离 |
| 高度统计 | 21 | 250m 内 Z 值的均值/最大/最小/高差 + P25/P50/P75 |
| 方向对齐 | 72 | 每半径正对网格视点数/比例、alignment cos 均值/最大、最近正向距离、方向核 |
| 建筑上下文 | 16 | 100/250m 内唯一建筑数、每建筑窗口数、正对窗口比例/距离、高低层窗口比 |
| 道路/高度上下文 | 14 | SVI 唯一道路数、DVI 唯一点位/高度层数、正对比例 |
| 距离衰减核 | 9 | exp(-d/50)、exp(-d/100)、exp(-d/250) |
| 建筑遮挡代理 | 21 | 立面法向量点积、建筑高度统计、体量代理 |

### 2.2 空间分布特征（18 维）

对三类观察点在 100m 和 250m 半径内计算：

| 特征 | 说明 |
|------|------|
| 角度熵 | 视点方向分布的 Shannon 熵（均匀 vs 集中） |
| 象限比 | 四个象限视点密度的最大/最小比（方向聚集度） |
| 聚类比 | 最近距离与平均距离之比（空间聚集度） |

### 2.3 特征预处理

- 计数类特征做 log1p 变换
- 所有特征在训练集上拟合 StandardScaler（均值 0，标准差 1）
- NaN/Inf 替换为 0

### 2.4 禁止使用的特征

- R/G/B 颜色值
- total_pixel、count、img_id、pixel_wvi
- 任何 GVVI 真值（S/W/D/综合）
- 邻居节点的 GVVI 标签
- 从测试集标签计算的统计量

## 三、图结构

使用网格中心坐标（香港 1980 Grid，EPSG:2326）的 k=8 空间 kNN 图。

- 节点：27,597
- 边：245,724（无向化后）
- 平均度：8.9
- 连通分量：5（最大分量 27,503 节点）
- 边特征：未使用（GraphSAGE 不依赖边特征）

## 四、模型

### 4.1 架构

```
输入 (214 维)
  → Linear(214, 256) + BatchNorm + GELU + Dropout(0.15)
  → SAGEConv(256, 256) + BatchNorm + GELU + Dropout(0.15)
  → SAGEConv(256, 128) + BatchNorm + GELU
  → Linear(128, 64) + GELU + Dropout(0.15)
  → Linear(64, 5)
  → 五档 logits
```

- 总参数量：263K
- 层数：2 层 GraphSAGE（不超过 4 层，避免过平滑）

### 4.2 损失函数

**Class-Balanced Focal Loss + 序数惩罚**

```python
L = FocalLoss(logits, targets, gamma=1.5, class_weights=CB)
  + 0.3 × SmoothL1(expected_class, true_class)
```

- Focal γ=1.5：聚焦难分样本
- Class-balanced weights：按 effective number 加权 (β=0.999)
- Label smoothing=0.05：防止过拟合少数类
- 序数惩罚：预测概率的期望档位与真实档位的 SmoothL1

### 4.3 训练配置

| 参数 | 值 |
|------|-----|
| Optimizer | AdamW |
| Learning rate | 1e-3 |
| Weight decay | 1e-4 |
| LR schedule | ReduceLROnPlateau (factor=0.5, patience=30) |
| Min LR | 1e-6 |
| Max epochs | 1,500 |
| Early stopping patience | 150 |
| Gradient clipping | 5.0 |
| Batch size | 全图（27,597 节点一次前向） |
| Seed | 42 |

## 七、局限与分析

### 7.1 主要瓶颈

1. **C2（5-15 档）准确率仅 19%**：该档处于"有点绿化但不明显"的模糊中间地带，几何特征缺乏足够区分力
2. **C3/C4 过拟合**：训练集分别只有 541/54 个样本，模型在训练集上表现良好（86%/100%）但在测试集坍塌（32%/25%）
3. **特征信号天花板**：214 维特征均为视点统计代理量，无法获取"相机视线是否被真实建筑物遮挡"这一关键信息
4. **GVVI 空间自相关弱**：相邻网格的 GVVI 差异 Spearman 相关系数仅 0.005，空间标签传播基本无效

### 7.2 为什么不是 90%

1. 几何特征只能表达"有多少观察点、距离多远、是否朝向网格"，不能表达"视线是否被建筑挡住"
2. 高值档（C3/C4）样本太少，无法学到可靠模式
3. C2 是天然的分类困难区——这个区间的网格确实在"微量"和"中等"之间模糊

### 7.3 可能的突破方向

1. **建筑 3D 几何**：使用 LoD1/LoD2 建筑模型做真正的视域分析
2. **少量渲染视图**：为 5-10% 的关键网格渲染视图，作为半监督信号
3. **DSM/DTM**：数字表面模型计算每个视点的可见天际线
4. **多城市数据**：增加样本多样性，缓解小类过拟合

### 7.4 诚实声明

- 测试集 4,146 节点从项目初期冻结，所有实验全程未变
- 档位边界仅用训练集确定，测试标签未参与
- 所有指标可从 `predictions.csv` 独立复算
- 模型未使用渲染视图、可见像素或 GVVI 真值作为输入特征
- 任务为同研究区传导式节点分类，不是跨区域泛化
